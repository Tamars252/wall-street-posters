# Wall Street Posters

A one-page website for an imaginary campus pop-up shop that sells posters to students, in Syracuse orange and blue.

Features:
- Posters that "slap" onto the wall when the page loads
- The **Poster Tube**: click to unroll a random poster, with confetti
- A shop grid with hover-to-lift posters and an add-to-wall cart counter

Open `index.html` in any browser. No build step or dependencies.
